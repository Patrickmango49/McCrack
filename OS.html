McCrack — Development History

Release notes for the continuing evolution of McCrack-COS.

1.0.0March 25
  • Added multi-page navigation, a settings panel, wallpapers, favicon support, and new homepage features.
  • Enhanced the homepage with a feature grid, live time and battery widgets, and a visitor counter.
  • Created the modern dark-gradient landing page with a top navigation system.
  • Completed a full UI visual overhaul and added the project README.
  • Redesigned the homepage into a cleaner dashboard-style layout.
1.0.1March 26
  • Redesigned the homepage with a monochrome visual theme and added Browser and McCrackOS navigation links.
1.0.2March 27
  • Added editable 50×5 games grids and improved site search with hash-based targeting.
  • Added popular-games highlight tiles and site-wide navbar search.
  • Increased embed sizes and fixed game fullscreen behavior.
  • Adjusted centered embeds, navigation order, animated titles, and gradient wallpaper presets.
  • Refined embed pages, centered embeds and fullscreen behavior, reordered homepage tiles, and removed wallpaper uploading.
  • Added in-page Chat, Browser, and McCrackOS embeds with fullscreen support.
  • Made the media grid 50×5 and added automatic launcher iframe sizing.
  • Made Games and Movies cards editable through per-page mediaData JSON.
  • Added an in-page media iframe launcher with a close control.
  • Changed media tiles to square layouts and generated 50×5 grids for Movies and Games.
  • Centered the overall layout, restored full-color images, and added subtle visual polish.

  • Updated movie embed URLs to use Google Drive preview formatting.

  • Added side advertisement units to the Home, Games, and Movies pages.

  • Added special alphabet handling for movie titles beginning with “The.”
